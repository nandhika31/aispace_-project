How space changes are verified

A difference between two sky images may be caused by noise, alignment, exposure or a real object change. This dashboard should compare calibrated observations, match sources by sky coordinates and cross-check candidates with trusted catalogues before calling them discoveries.

Evidence-first detection
SPHEREx is an infrared sky-survey mission, not a live meteor-warning or continuous comet-tracking service. Use dedicated catalogues for confirmed object information.
